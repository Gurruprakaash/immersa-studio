# Immersa Studio

## Overview

Immersa Studio is a web-based platform concept designed to bring augmented reality (AR), virtual reality (VR), and 3D content exploration into one unified workspace. It provides a user-friendly interface for exploring immersive environments, managing creative projects, viewing 3D models, and previewing AR experiences.

The project focuses on a professional desktop experience with an organized dashboard, intuitive navigation, and dedicated workspaces for different immersive design activities.

## Features

- **User Login:** A dedicated entry screen with guest access for exploring the platform.
- **Dashboard:** A central workspace for accessing projects and platform features.
- **Explore Gallery:** Browse immersive content and creative examples.
- **My Projects:** Access and organize project resources.
- **Create Project:** Start new immersive design projects.
- **3D Model Explorer:** Explore 3D models through a dedicated interface.
- **VR Environment Explorer:** Navigate and explore virtual environments.
- **AR Experience Preview:** Preview augmented reality experiences.
- **Spatial Engine Workstation:** Access a dedicated spatial design workspace.
- **Studio Settings:** View and manage platform preferences.

## Technology Stack

- HTML5
- CSS3
- JavaScript
- Google Stitch for UI/UX design and prototyping

## Project Structure

The project is organized into separate interface screens, with each screen representing a specific feature or workspace.

- `login_welcome/` – Login screen design
- `main_dashboard/` – Main dashboard
- `explore_gallery/` – Content gallery
- `my_projects_library/` – Project library
- `create_project/` – Project creation interface
- `3d_model_explorer/` – 3D model exploration
- `vr_environment_explorer/` – VR environment interface
- `ar_experience_preview/` – AR preview interface
- `studio_settings/` – Settings interface
- `spatial_engine_workstation/` – Spatial design workspace

## Getting Started

1. Download or clone this repository.
2. Locate the selected login screen's `code.html` file.
3. Open `code.html` in a modern web browser.
4. Use the available guest access option to explore the interface.

For the best experience, use a modern desktop browser such as Google Chrome.

## Project Objectives

- Create a professional and user-friendly interface for AR/VR workflows.
- Organize immersive design tools into a unified workspace.
- Demonstrate UI/UX design and multi-page navigation.
- Provide a foundation for future integration of 3D rendering, AR/VR technologies, and backend services.

## Current Scope

Immersa Studio is currently a UI/UX prototype. Features such as authentication, persistent project storage, live 3D rendering, and actual AR/VR device integration may require additional implementation beyond the interface prototype.

## Future Enhancements

- Integrate a backend for user accounts and project management.
- Add interactive 3D model rendering.
- Support real-time AR/VR previews.
- Implement project saving and collaboration.
- Improve accessibility and responsive design.
- Add secure authentication and cloud storage.
